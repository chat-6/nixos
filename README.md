# NixOS configs

Multi-host flake. `modules/` is shared between every machine;
`hosts/<name>/` holds hardware- and machine-specific config.

```
.
├── flake.nix
├── modules/                  # shared across all hosts
│   ├── networking-base.nix   # NetworkManager
│   ├── locale-base.nix       # timezone + i18n (not keymap)
│   ├── audio-base.nix        # pipewire
│   └── vim.nix
└── hosts/
    ├── desktop/               # Nvidia desktop, Plasma, Steam
    │   ├── configuration.nix
    │   ├── hardware-configuration.nix   # <- REPLACE with the real one
    │   ├── boot.nix
    │   ├── graphics.nix       # nvidia
    │   ├── desktop.nix        # plasma/wayland/xdg-portals
    │   ├── audio.nix          # MiniFuse wireplumber fix
    │   ├── users.nix
    │   ├── programs.nix       # firefox, steam
    │   ├── filesystems.nix    # windows ntfs mount
    │   ├── networking.nix     # avahi + extra firewall ports
    │   ├── locale.nix         # de keymap
    │   └── pkgs.nix           # full package list
    └── macbook/                # 2011 13" MacBook Pro, Intel only
        ├── configuration.nix
        ├── hardware-configuration.nix   # real, from nixos-generate-config
        ├── boot.nix
        ├── graphics.nix        # intel (no nvidia)
        ├── wifi.nix            # broadcom_sta / "wl" driver
        ├── users.nix
        ├── programs.nix        # firefox, printing (steam commented out)
        ├── locale.nix          # us keymap
        └── pkgs.nix            # trimmed package list
```

## Deploying

From a clone of this repo on the target machine:

```sh
sudo nixos-rebuild switch --flake .#desktop
# or
sudo nixos-rebuild switch --flake .#macbook
```

## Adding a new host

1. `mkdir hosts/<name>`
2. Boot the NixOS installer on the machine, run
   `nixos-generate-config --root /mnt`, and copy the real
   `hardware-configuration.nix` it produces into `hosts/<name>/`.
3. Write a `configuration.nix` there that imports the shared
   `modules/*` plus whatever host-specific files it needs.
4. Add a `nixosConfigurations.<name>` entry in `flake.nix`.

## Notes

- **`hosts/desktop/hardware-configuration.nix` is currently a
  placeholder.** It was never generated/uploaded here — replace it
  with the real file from `/etc/nixos/hardware-configuration.nix` on
  the desktop before building that host.
- Don't hand-edit `hardware-configuration.nix` files or share them
  between hosts — they're machine-specific (disk UUIDs, detected
  kernel modules) and regenerated by `nixos-generate-config`.
- `system.stateVersion` is intentionally different per host (25.11 vs
  26.05) — leave each one at whatever it was originally installed
  with; don't "sync" this value between hosts.
